\section{空间曲线的投影}

空间曲线$\Gamma$
\[
\left \{ \begin{aligned}
F(x,y,z) = 0 \qquad \text{①} \\
G(x,y,z) = 0 \qquad \text{②}
\end{aligned} \right.
\]
求$\Gamma$在坐标面上的投影曲线
以XY面为例,联立①②消去z即可
得到方程$H(x,y)=0$
它是一个柱面且过曲线$\Gamma$,再将柱面与$z=0$相交得到投影曲线
\[
\left \{ \begin{aligned}
H(x,y) = 0 \\
z = 0 
\end{aligned} \right.
\]

\[
\Gamma \left \{ \begin{aligned}
x^2 + y^2 + z^2 = a^2\\
x^2 + y^2 -ax = 0
\end{aligned} \right.
\]

\left \{ \begin{aligned}
x^2 + y^2 - ax = 0 \\

\end{aligned} \right.
