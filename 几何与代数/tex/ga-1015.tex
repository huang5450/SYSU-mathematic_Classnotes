\subsection*{1. 空间曲线的投影}
空间曲线$\Grmma$
\[
\left \{ \begin{aligned}
F(x,y,z) = 0 \tag{①} \\
G(x,y,z) = 0 \tag{②}
\end{aligned} \right.
\]
求$Grmma$在坐标面上的投影曲线
以XY面为例,联立①②消去z即可
得到方程$H(x,y)=0$
它是一个柱面且过曲线$\Grmma$,再将柱面与$z=0$相交得到投影曲线
\[
\left \{ \begin{aligned}
H(x,y) = 0 \\
z = 0 
\end{aligned} \right.
\]
